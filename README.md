# 🦷 DentalVision AI — Panoramic Dental Radiography Pathology Detection

Automated Deep Learning Multi-Disease Pathology Analysis for Panoramic Dental Radiographs (OPGs) trained on the **DENTEX** benchmark dataset (*Hamamci et al., MICCAI 2023*).

> **Medical Disclaimer**:
> This software is a **research prototype** and **not a certified diagnostic medical device**.
> The outputs, probabilities, and visual attention maps generated by this system are for educational and research exploration only. All radiographic observations must be verified by a licensed dental professional.

---

## 🎯 Target Pathologies (DENTEX Benchmark)
The model is trained on ground-truth bounding box and multi-label annotations from the official **DENTEX 2023 Challenge** (`categories_3`):

1. **Caries (Coronal / Interproximal):** Enamel and dentin demineralization causing radiolucency.
2. **Deep Caries:** Advanced dentinal caries approaching or contacting the dental pulp.
3. **Periapical Lesions (Apical Periodontitis):** Radiolucent areas surrounding root apices indicating inflammation, granuloma, or cyst.
4. **Impacted Teeth:** Teeth prevented from erupting into normal physiological occlusion (frequently third molars).

*(Note: Periodontitis was excluded from earlier iterations because public benchmark annotations with reliable ground truth were not provided in the primary dataset.)*

---

## 🏗️ Architecture & Explainable AI
- **Backbone**: Deep Residual Network (`ResNet50`) with an adaptive pooling layer and multi-label classification head.
- **Explainability**: Authentic gradient-weighted class activation mapping (**Grad-CAM**) visualizing neural activations in the final convolutional block (`layer4`).
- **Radiograph Enhancement**: Contrast Limited Adaptive Histogram Equalization (**CLAHE**) and grayscale inversion tools.
- **Inference Module**: Unified pipeline in `backend/inference.py` shared across UI and API.

---

## 📊 Dataset: DENTEX (MICCAI 2023)
- **Source**: Hugging Face [`ibrahimhamamci/DENTEX`](https://huggingface.co/datasets/ibrahimhamamci/DENTEX)
- **License**: CC BY-NC-SA 4.0 (Non-commercial research use)
- **Splits**:
  - **Train**: 564 images (stratified 80% split from 705 annotated training radiographs)
  - **Validation**: 141 images (stratified 20% holdout for early stopping)
  - **Test**: 50 images (official DENTEX validation split with ground-truth labels in `validation_triple.json`)

## 🚀 Quickstart

### 1. Installation
```bash
git clone https://github.com/AhmadBurhan676/dental-disease-detection.git
cd dental-disease-detection
pip install -r requirements.txt
```

### 2. Dataset Download & Preparation
Download annotations, build patient-leak-free splits, and stream the target disease images:
```bash
python scripts/download_dataset.py
```

### 3. Model Training
Train the ResNet50 model honestly on the real training split:
```bash
python -m backend.train --epochs 20 --batch-size 8 --lr 0.0001
```
The best checkpoint is saved to `models/dental_model.pth`, and training convergence metrics are logged to `models/training_history.json`.

### 4. Evaluation
Evaluate the trained checkpoint on the held-out test split:
```bash
python scripts/evaluate.py
```
This writes `models/metrics.json` containing per-class precision, recall, F1, specificity, and ROC-AUC with 95% bootstrap confidence intervals, alongside ROC curves and confusion matrices in `static/`.

### 5. Launch Application
Start the Streamlit clinical interface:
```bash
streamlit run streamlit_app.py
```
Or start the FastAPI backend:
```bash
python -m backend.app
```
